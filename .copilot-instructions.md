# Copilot Instructions — mcp-context-cache

This MCP server provides intelligent context caching tools for AI agents working with large codebases.

## Project Overview

**mcp-context-cache** is a Model Context Protocol server that helps AI agents manage and load project context efficiently through three main tools:

- `get_project_context` - Load specific files into context
- `get_directory_context` - Load all files from a directory
- `get_context_from_config` - Load curated context from `contextcache.json`

## When Working on This Project

### Guidelines for Context Loading
1. Use `get_context_from_config` first if a `contextcache.json` exists in the project being analyzed
2. Fall back to `get_directory_context` for module-level exploration
3. Use `get_project_context` for targeted file loading when paths are known

### Code Patterns to Follow
- Use Zod for schema validation (see `types.ts`)
- Implement security checks via `SecurityGuard` for path validation
- Use LRU cache for performance-critical operations
- Add tests alongside feature implementations

### Security Considerations
- Always validate file paths before processing
- Respect ignore patterns defined in `contextcache.json`
- Never process files outside project boundaries
- Log security-relevant operations

## Gestión de Contexto con MCP Context Cache

Para leer archivos o módulos del proyecto, usa SIEMPRE las herramientas del servidor MCP `mcp-context-cache`:

1. Si existe `contextcache.json` en la raíz del proyecto:
   - Usa `get_context_from_config` con la ruta de la raíz del proyecto.
   - Esto te dará el contexto completo optimizado para caché de tokens.

2. Si NO existe `contextcache.json`:
   - Si necesitas un módulo o carpeta completa, usa `get_directory_context`.
   - Si necesitas archivos específicos, usa `get_project_context` con la lista de rutas.

3. NUNCA uses `read_file` individual para leer archivos de código fuente uno por uno.
   Esto rompe el caché de tokens del LLM y multiplica el costo de tokens.

4. Si el contexto devuelto indica `BUNDLE_TRUNCATED`, puedes solicitar los archivos
   omitidos con `get_project_context` usando sus rutas específicas.
